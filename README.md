# DotA-v6.78c-AI-1.5a-Encore
A long overdue update to the legacy of the dota1 AI map. This version of the map is for pre-reforged w3c TFT (tested on v1.27b - just like the good old days).

This is an update to the final AI version released by the heroes of my childhood:
PleaseBugMeNot, Cloud, Sebra, Gabo, Ciel, Green.

Their "Farewell" version of the map contained many bugs that have now finally been patched.
- The full hero pool is now rolled properly for modes such as ar and sd. There were many compounding incorrect restrictions that severely reduced the probability of seeing some heroes.
- Fixed modes such as -aa, -ai and -as to behave as intended
- All heroes have an assigned AI behavior role now (something that helps pilot them better)
- Fixed heroes walking along with macropyre and meteor leading to invoker and jakairo AI being OP against other AI.
- AI now lanes more aggressively and takes the obvious free windows to weave more auto attacks at you when you are trying to last hit.
- AI now coordinates ganks better, except some neat jungle action!
- AI now does some basic warding to provide limited vision.
